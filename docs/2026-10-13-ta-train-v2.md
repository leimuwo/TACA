| 用途 | pair | 正 | 负 | 轨迹 |
| --- | ---: | ---: | ---: | ---: |

排除统计记录在 `manifest.json`。这些都是 GQQ 弱监督标签，内部验证也来自 train 轨迹，只能检查训练链路和相对变化，不能报告独立泛化性能。需要扩容时优先人工裁定不确定窗口、补原子 Intent 和独立 dev/test Gold；不要直接放宽过滤条件。

## GPU 训练

在安装 `torch`、`transformers` 且可访问本地 BGE-M3 的 GPU 环境，从 Project 目录运行：

```bash
python scripts/train_ta_pair_reranker.py --data data/clawgym/ta_pair_weak_train_v1_20261013 --model /inspire/hdd/project/control-technology/public/model_hub/bge-m3 --output outputs/ta_pair_bge_m3_exploratory_v1 --device cuda
```

本地 BGE-M3 是编码器，脚本在其上初始化一个新的单 logit 分类头，联合编码 Intent 与原始 Action，用二元交叉熵微调整个编码器和分类头。它不是沿用 BGE-M3 的原双塔余弦检索头。每 20 batch 报进度，按内部验证 pair F1 保存 `best/` 和 `training_report.json`。此版本是训练试验，不应与旧检索 reranker 的 MRR 指标混用。当前 CPU 容器没有 `torch`/`transformers` 和可用 GPU，已完成 dry-run 与数据防泄漏测试，尚未生成模型权重。

使用预训练 Cross-Encoder `bge-reranker-v2-m3` 作对照，复用同一份 train 和按轨迹隔离的内部验证 pair：

```bash
python scripts/train_ta_pair_cross_encoder.py --output outputs/ta_pair_cross_encoder_v1 --device cuda
```

这一版从本地 reranker 加载**已有的单 logit 分类头**，继续用二元交叉熵微调。两个脚本的输入、训练超参数和内部验证指标一致；两者都不是独立 dev/test 评测。
